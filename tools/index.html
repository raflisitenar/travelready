Why we made these tools

A generic checklist cannot tell whether a passport is valid for a particular route or whether a certain bag fits a fare category. It can, however, remind you to check those facts and help organize what you learn. The Packing Builder is intentionally designed around categories of tasks, with important verification prompts rather than made-up certainty. The timeline planner uses an approximate planning sequence and is not a set of regulatory deadlines.

Start with our document verification workflow and travel-day guide if you want context for the tool results.
